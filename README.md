## 📝 Περιγραφή (Project Overview)
Αυτό το project αποτελεί μια ολοκληρωμένη μελέτη και υλοποίηση πολυδιάστατων χωρικών δομών δεδομένων (Spatial Data Structures) σε περιβάλλον τρισδιάστατου (3D) χώρου. Σκοπός του project είναι η σύγκριση της αποδοτικότητας δύο βασικών δομών διαχωρισμού χώρου, του **Kd-Tree (K-Dimensional Tree)** και του **Octree**, ως προς τον χρόνο εκτέλεσης βασικών λειτουργιών (Εισαγωγή, Αναζήτηση, Διαγραφή, Ενημέρωση), καθώς και η ενσωμάτωση του αλγορίθμου **LSH (Locality-Sensitive Hashing)** για την εύρεση πλησιέστερου γείτονα (Nearest Neighbor Search).

Τα δεδομένα εισάγονται από ένα αρχείο κειμένου (`test.txt`), όπου κάθε γραμμή αναπαριστά ένα σημείο στο 3D χώρο, κωδικοποιημένο με χαρακτήρες (π.χ. `['k','c','b']`), οι οποίοι μετατρέπονται σε τιμές ASCII για την επεξεργασία τους.

## 🏗️ Δομές Δεδομένων & Αλγόριθμοι (Data Structures)

### 1. Kd-Tree (K-Dimensional Tree)
* **Λειτουργία:** Δυαδικό δέντρο αναζήτησης που χρησιμοποιείται για την οργάνωση σημείων σε χώρο K διαστάσεων (στην περίπτωσή μας, K=3).
* **Αρχιτεκτονική:** Σε κάθε επίπεδο του δέντρου, ο διαχωρισμός του χώρου γίνεται κυκλικά ανά άξονα (Depth % 3). Το project υλοποιεί εύρεση διαμέσου (median) κατά την κατασκευή για τη διατήρηση της ισορροπίας του δέντρου, καθώς και δυναμική εισαγωγή/διαγραφή κόμβων με ανακατασκευή υποδέντρων όπου απαιτείται.

### 2. Octree
* **Λειτουργία:** Ιεραρχική δομή δεδομένων όπου κάθε εσωτερικός κόμβος έχει ακριβώς οκτώ (8) παιδιά.
* **Αρχιτεκτονική:** Χωρίζει τον τρισδιάστατο χώρο σε 8 οκτάντια (octants) με βάση τις συντεταγμένες του τρέχοντος κόμβου-ρίζας. Η πλοήγηση και η τοποθέτηση των σημείων καθορίζεται από τη συνάρτηση `get_dir()`, η οποία ελέγχει σε ποιό οκτάντιο ανήκει το σημείο ως προς τον πατέρα του.

### 3. Locality-Sensitive Hashing (LSH)
* **Λειτουργία:** Αλγόριθμος κατάλληλος για Approximate Nearest Neighbor (ANN) αναζητήσεις σε χώρους πολλών διαστάσεων.
* **Αρχιτεκτονική:** Μέσω της βιβλιοθήκης `LSHash`, οι συντεταγμένες των δέντρων μετατρέπονται σε διανύσματα ASCII, ευρετηριάζονται, και εκτελείται αναζήτηση (`query`) για τον εντοπισμό του πιο κοντινού σημείου με βάση τη μαθηματική τους εγγύτητα.

## 🛠️ Τεχνολογίες & Περιβάλλον Ανάπτυξης (Tech Stack & Environment)

* **Γλώσσα Προγραμματισμού:** Python 3
* **Περιβάλλον Ανάπτυξης (IDE):** Python IDLE (Integrated Development and Learning Environment)
* **Λειτουργικό Σύστημα Δοκιμών:** Windows 10
* **Βασικές Βιβλιοθήκες:**
  * `lshash` (ή `lshashpy3`): Για την υλοποίηση του Locality-Sensitive Hashing.
  * `timeit` (`default_timer`): Για τη μέτρηση ακριβείας των χρόνων εκτέλεσης σε micro/milliseconds.
  * `operator` (`itemgetter`): Για τη γρήγορη ταξινόμηση και εύρεση διαμέσου στους άξονες του Kd-Tree.
  * `csv` & `math`: Για τη διαχείριση δεδομένων και μαθηματικούς υπολογισμούς.

## 📐 Αρχιτεκτονική Κώδικα (Code Architecture)

Το project είναι δομημένο με αντικειμενοστραφή προσέγγιση (OOP) και περιλαμβάνει τις εξής βασικές μεθόδους ανά κλάση (`Kdtree` & `Octtree`):

| Μέθοδος | Λειτουργία |
| :--- | :--- |
| `__init__` | Αρχικοποίηση και έναρξη κατασκευής του δέντρου από λίστα σημείων. |
| `build()` | Αναδρομική κατασκευή (Top-Down) της δομής. |
| `search()` | Έλεγχος ύπαρξης ενός σημείου στο δέντρο. |
| `insert()` | Δυναμική εισαγωγή νέου σημείου στη σωστή θέση. |
| `delete()` | Αφαίρεση σημείου και αυτόματη αναδιοργάνωση των παιδιών του. |
| `update()` | Ενημέρωση υπαρκτού σημείου (διαγραφή παλιού και εισαγωγή νέου). |
| `find_nearest()` | Εύρεση του πλησιέστερου γείτονα με τη χρήση LSH. |
| `get_children()` | Εξαγωγή όλων των απογόνων ενός κόμβου με τη χρήση ουράς (BFS). |

## 🚀 Οδηγίες Εκτέλεσης (How to Run)

1. **Λήψη του Project:**
   Κατεβάστε τα αρχεία κώδικα απευθείας από την ιστοσελίδα του GitHub (κουμπί *Code -> Download ZIP*) και αποσυμπιέστε τα σε έναν φάκελο.

2. **Εγκατάσταση της βιβλιοθήκης LSH:**
   Ανοίξτε τη Γραμμή Εντολών (Command Prompt) των Windows και εγκαταστήστε την απαραίτητη βιβλιοθήκη:
   ```bash
   pip install lshashpy3
   ```

3. **Προετοιμασία των δεδομένων:**
   Βεβαιωθείτε ότι το αρχείο `test.txt` βρίσκεται **στον ίδιο ακριβώς φάκελο** με τα αρχεία κώδικα, περιέχοντας 3-γράμματες συμβολοσειρές ανά γραμμή:
   ```text
   abc
   xyz
   kcb
   ```

4. **Εκτέλεση στο Python IDLE:**
   * Κάντε δεξί κλικ στο αρχείο `kdtree.py` ή `octree.py` και επιλέξτε **Edit with IDLE**.
   * Μόλις ανοίξει το παράθυρο του κώδικα, πιέστε το πλήκτρο **F5** (ή επιλέξτε *Run -> Run Module*) για να εκτελεστεί το benchmark και να δείτε τους μέσους χρόνους εκτέλεσης στην κονσόλα.

## 📊 Αποτελέσματα & Συμπεράσματα (Benchmarking)
Κάθε αρχείο περιλαμβάνει αυτοματοποιημένα test σενάρια που μετρούν τον μέσο χρόνο εκτέλεσης 5 τυχαίων πράξεων. Τα αποτελέσματα εκτυπώνονται στην κονσόλα και επιτρέπουν τη σύγκριση των δομών:
* Το **Kd-Tree** υπερέχει σε ομοιογενώς κατανεμημένα δεδομένα λόγω της ισορροπημένης κατασκευής του μέσω διαμέσου.
* Το **Octree** προσφέρει ταχύτατο διαχωρισμό σε καθαρά 3D προβλήματα, αλλά η απόδοσή του εξαρτάται από τη σειρά εισαγωγής των δεδομένων.
